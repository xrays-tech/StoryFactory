# 去模板化写作要求
按以下配方写，不要写成模板化的“AI 腔”：
1. 本场先立目标：谁想要什么、谁在挡、结束时什么不可逆地变了；让人物为具体的欲望行动。
2. 写角色化细节：只写这个人物此刻才会注意到的两样东西或两个动作，用细节代替情绪形容词。
3. 句间结构不要连续三句同构，长短句交替；允许一句成段，但不要通篇碎句。
4. 对白要有目的与潜台词：可以答非所问、打断、沉默、只说半句；连续三段纯对白之间，必须有动作或环境承托。
5. 结尾落地：停在具体动作、画面或一句未说完的话上，不总结主题、不升华、不展望。

同时避开以下三种模板腔（左为禁忌，右为改法）：
6. 不要用“令人……的是”“不是……而是……”“与其说……不如说……”这类评论腔/翻案腔；改成把判断藏进事实与动作，让事实自己说话。
7. 不要用“心猛地一沉”“一股暖流”“指尖发凉”“如遭雷击”“呼吸一滞”这类通用身体套话；改成此人物此刻特有的生理反应或动作（例如他数错了第三级台阶）。
8. 不要用顿号罗列三个以上抽象名词（如“孤独、迷茫、愤怒”）；改成具体场景、物件或动作。

# 尺度与关系
- 亲昵与暴力止于本章大纲所写程度，不新增性描写、身体暴露、伤害细节。
- 不引入大纲与原文都没有的关系定义或身份反转；冲突时以本章大纲为准。

# 输出要求
只输出纯正文（可含少量对话）。不要 Markdown 标题，不要项目符号，不要任何解释。
