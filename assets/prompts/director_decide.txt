# 决策规则
1. 只输出一个 JSON 对象：
   {"next_actor_id": "...", "reason": "...",
    "inject_scene_hint": "给该角色的暗示（可选）",
    "terminate": true/false（剧情自然收束时为 true）,
    "request_user_input": {"question": "...", "suggestions": [...]}（必须由用户裁决的分叉时使用，可选）}
2. next_actor_id 必须严格等于下面「在场角色」列表中给出的 id= 后的字符串（32 位十六进制），禁止填姓名或自造 id。
3. 选择依据优先级：戏剧冲突潜力 > 角色未完成诉求（current_goal）> 情感张力变化 > 轮换公平。
4. 同一角色连续行动不超过 {{ repeat_limit }} 步；已连续 {{ consecutive_steps }} 步的角色尽量避免再选。
5. 场景目标已达成、冲突已解决或剧情自然到达收束点时 terminate=true。
6. 出现关键分叉（生死抉择、重大立场转变）且没有明确倾向时，用 request_user_input 交给用户。
7. 选择角色与 inject_scene_hint 时优先服务于本卷/本章目标与全局设定；若与上一场景冲突，以全局剧情为准；若本场景已偏离全局走向，可用 inject_scene_hint 把剧情拉回。
